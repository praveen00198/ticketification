# Design System & Visual Architecture

## Visual Identity: Operational Event Console
- **Primary Background**: Warm Off-White (`#FAF9F6`)
- **Surfaces & Cards**: Pure White (`#FFFFFF`) / Crisp Border (`#E4E4E7`)
- **Primary Text**: Deep Charcoal (`#18181B`)
- **Secondary Text**: Muted Slate (`#71717A`)
- **Accent Brand Color**: Event Vermilion (`#DC2626`)
- **Success / Active**: Restrained Emerald (`#10B981`)
- **Warning / Used**: Warm Amber (`#F59E0B`)
- **Error / Invalid**: Crisp Crimson (`#EF4444`)

## Signature Visual Element: Perforated Credential Language
Subtle sawtooth notch cutouts and dashed separator line styling (`ticket-perforation-notch`, `border-dashed`) applied to ticket cards, data previews, and scanner result cards to instantly convey physical credential context without gimmicks.
